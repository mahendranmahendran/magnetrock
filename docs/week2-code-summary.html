Day 8

GeoJSON Coverage Zones

Goal: Colour-coded zone polygons overlaid on the map
What This Does (Task)
  • Defines three London coverage zones as GeoJSON polygons: Central (£70), Inner (£50), Outer (clinic only)
  • Overlays them on the MapLibre map as fill + dashed-outline layers
  • Adds a toggle switch + Fixed/Drive-Time tab bar below the map via CoverageLayer component
  • Zone visibility updates reactively when toggle is flipped
Pseudocode
-- data/coverage-zones.json
FeatureCollection {
  features: [
    Feature { zone:"central", fee:70, Polygon }
    Feature { zone:"inner",   fee:50, Polygon }
    Feature { zone:"outer",   fee:0,  Polygon }
  ]
}

-- ClinicMap.tsx (inside map.on('load'))
addSource('coverage', { type:'geojson', data: emptyFC })
addLayer('coverage-fill',    type:fill,    visibility:'none')
addLayer('coverage-outline', type:line,    visibility:'none')
coverageReady = true

-- when coverageZones prop changes:
IF map ready → source.setData(coverageZones)

-- when showZones prop changes:
IF map ready → setLayoutProperty(visibility)
React / TSX Code Snippet — ClinicMap.tsx (zone additions)
// New props added to ClinicMap
type Props = {
  clinics: Clinic[];
  coverageZones?: object | null;   // GeoJSON FeatureCollection
  showZones?: boolean;
  // ...existing props
};

// Refs that track latest prop values (needed for map.on('load') timing)
const coverageReadyRef = useRef(false);
const coverageZonesRef = useRef(coverageZones ?? null);
const showZonesRef     = useRef(showZones);

// Inside map.on('load') — after route source/layer setup:
map.addSource('coverage', { type: 'geojson', data: emptyFC });
map.addLayer({
  id: 'coverage-fill', type: 'fill', source: 'coverage',
  layout: { visibility: 'none' },
  paint: {
    'fill-color': ['match', ['get', 'zone'],
      'central', '#22c55e',
      'inner',   '#eab308',
      /* default */ '#ef4444'],
    'fill-opacity': 0.15,
  },
}, 'route'); // insert below route layer
map.addLayer({
  id: 'coverage-outline', type: 'line', source: 'coverage',
  layout: { visibility: 'none' },
  paint: {
    'line-color': ['match', ['get', 'zone'],
      'central', '#16a34a', 'inner', '#ca8a04', '#dc2626'],
    'line-width': 2,
    'line-dasharray': [4, 2],
  },
}, 'route');
coverageReadyRef.current = true;

// Reactive useEffect — updates map when prop changes
useEffect(() => {
  coverageZonesRef.current = coverageZones ?? null;
  if (!mapRef.current || !coverageReadyRef.current) return;
  (mapRef.current.getSource('coverage') as any)?.setData(coverageZones ?? emptyFC);
}, [coverageZones]);

useEffect(() => {
  showZonesRef.current = showZones;
  if (!mapRef.current || !coverageReadyRef.current) return;
  const vis = showZones ? 'visible' : 'none';
  mapRef.current.setLayoutProperty('coverage-fill',    'visibility', vis);
  mapRef.current.setLayoutProperty('coverage-outline', 'visibility', vis);
}, [showZones]);

Day 9

Isochrone Zones + Zone Decision

Goal: Drive-time zones fetched from Mapsi Isochrone API
What This Does (Task)
  • New server-side API route /api/isochrone proxies to mapsi.dev/v1/isochrone
  • Accepts lat, lon, minutes and returns GeoJSON polygons
  • The locations page fetches isochrones for the 3 nearest clinics when in "Drive-Time" mode
  • Fixed vs Drive-Time is a tab toggle in the CoverageLayer component
  • When no user location: shows a message to search first
Pseudocode
-- app/api/isochrone/route.ts
GET /api/isochrone?lat=X&lon=Y&minutes=15,30,45

  validate lat + lon present
  build URL → mapsi.dev/v1/isochrone?lat=X&lon=Y&minutes=...
  fetch with X-API-Key header
  return GeoJSON as-is

-- locations/page.tsx (useEffect)
WHEN zoneMode == 'isochrone' AND userLocation AND showZones:
  fetch /api/isochrone for each of nearest 3 clinics
  merge all returned features into one FeatureCollection
  setCoverageZones(merged)

WHEN zoneMode switches back to 'fixed':
  setCoverageZones(zonesData)  ← local JSON, no API call
API Route — app/api/isochrone/route.ts
import { NextRequest, NextResponse } from 'next/server';

export async function GET(request: NextRequest) {
  const { searchParams } = request.nextUrl;
  const lat     = searchParams.get('lat');
  const lon     = searchParams.get('lon');
  const minutes = searchParams.get('minutes') ?? '15,30,45';

  if (!lat || !lon)
    return NextResponse.json({ error: 'Missing lat or lon' }, { status: 400 });

  const apiKey = process.env.NEXT_PUBLIC_MAPSI_API_KEY;
  if (!apiKey) return NextResponse.json({ error: 'API key not configured' }, { status: 500 });

  const url = `https://mapsi.dev/v1/isochrone?lat=${lat}&lon=${lon}&minutes=${minutes}`;
  const res = await fetch(url, { headers: { 'X-API-Key': apiKey } });

  if (!res.ok)
    return NextResponse.json({ error: 'Isochrone request failed' }, { status: res.status });

  // Mapsi returns GeoJSON FeatureCollection — pass through as-is
  return NextResponse.json(await res.json());
}
Locations Page — isochrone fetch logic
// useEffect fires when user switches to isochrone mode
useEffect(() => {
  if (zoneMode !== 'isochrone' || !userLocation || !showZones) return;
  let cancelled = false;
  setIsochroneLoading(true);

  (async () => {
    // Fire one request per nearest clinic (up to 3 in parallel)
    const targets = nearest.length > 0 ? nearest.slice(0, 3) : clinics.slice(0, 3);
    const results = await Promise.all(
      targets.map((c) =>
        fetch(`/api/isochrone?lat=${c.lat}&lon=${c.lng}&minutes=30`)
          .then((r) => r.json()).catch(() => null)
      )
    );
    if (cancelled) return;

    // Flatten all features from all isochrone responses
    const features = results
      .filter(Boolean)
      .flatMap((fc) => fc?.features ?? []);

    if (features.length > 0)
      setCoverageZones({ type: 'FeatureCollection', features });
  })().finally(() => { if (!cancelled) setIsochroneLoading(false); });

  return () => { cancelled = true; };
}, [zoneMode, userLocation, showZones, nearest]);

Booking Autocomplete + Coverage Check

Goal: As-you-type address suggestions + instant zone/fee result
What This Does (Task)
  • Address field on the booking form calls /api/geocode after the user stops typing (320ms debounce)
  • Suggestions dropdown appears below the input
  • On suggestion click: geocoded lat/lon sent to /api/coverage (Turf.js point-in-polygon server-side)
  • Response shows: "Home visit available — £50" or "Clinic visits only"
  • A mini-map appears showing the user's pin and their zone
Pseudocode
-- app/booking/page.tsx
STATE: suggestions, showSuggestions,
       coverageResult, userLocation

ON address input change:
  setFormData(address)
  clearTimeout(debounceTimer)
  debounceTimer = setTimeout(320ms):
    IF length >= 3:
      GET /api/geocode?q=address
      setSuggestions(results)

ON suggestion click:
  setAddress(suggestion.formatted_address)
  setUserLocation([lat, lon])
  GET /api/coverage?lat=...&lon=...
  setCoverageResult(response)
  → show coverage UI + mini-map

-- app/api/coverage/route.ts
GET /api/coverage?lat=X&lon=Y
  pt = turf.point([lon, lat])
  FOR zone IN [central, inner, outer]:
    IF turf.booleanPointInPolygon(pt, zoneFeature):
      RETURN { zone, fee, note }
  RETURN { zone: null, note: "Outside service area" }
Coverage API Route — app/api/coverage/route.ts (key logic)
import booleanPointInPolygon from '@turf/boolean-point-in-polygon';
import { point } from '@turf/helpers';
import zonesData from '@/data/coverage-zones.json';
import feesData  from '@/data/coverage-fees.json';

export async function GET(request: NextRequest) {
  const lat = parseFloat(searchParams.get('lat')!);
  const lon = parseFloat(searchParams.get('lon')!);

  const pt    = point([lon, lat]);   // GeoJSON is [lng, lat]
  const zones = zonesData.features;

  // Most specific first: central → inner → outer
  for (const zoneKey of ['central', 'inner', 'outer']) {
    const feature = zones.find((f) => f.properties?.zone === zoneKey);
    if (feature && booleanPointInPolygon(pt, feature)) {
      const fee = feesData[zoneKey];
      return NextResponse.json({ zone: zoneKey, ...fee });
    }
  }
  return NextResponse.json({ zone: null, note: 'Outside service area' });
}

Mini-Map on Booking + Matrix API Drive-Time

Goal: Visual location preview + real drive-time clinic ranking
Mini-Map Task
  • ClinicMiniMap component: 180px-tall MapLibre map, interactive: false
  • Accepts userLocation, zone, nearestClinicLocation
  • Shows blue dot (user), green dot (nearest clinic)
  • Zone header bar coloured by zone type (green/amber/red)

  • Returns drive time in seconds + minutes, sorted nearest-first

Day 12

Performance Optimisations

Goal: Faster loads, fewer redundant fetches, better mobile UX
What's Already In Place
  • Lazy loading: ClinicMap and ClinicMiniMap are both wrapped in next/dynamic({ ssr: false }) — MapLibre is never bundled server-side
  • Tile caching: /api/tiles sets Cache-Control: public, max-age=86400 — tiles are cached 24 hours
  • Style caching: Map style JSON cached 1 hour
  • Autocomplete debounce: 320ms delay prevents API hammering while typing
  • Request cancellation: All async useEffects use a cancelled flag to ignore stale responses
localStorage Caching Pattern
-- Pattern for caching isochrone data
-- (avoids re-fetching on page revisit)

FUNCTION loadZonesWithCache(clinicId, minutes):
  key = `isochrone_${clinicId}_${minutes}`
  cached = localStorage.getItem(key)
  IF cached AND not expired (< 1 hour):
    RETURN JSON.parse(cached)

  data = await fetch(`/api/isochrone?...`)
  localStorage.setItem(key, JSON.stringify({
    data, timestamp: Date.now()
  }))
  RETURN data

-- Why: Isochrone API costs rate-limit quota.
-- Zones don't change minute-to-minute.
-- 1-hour TTL = cheap + fresh enough.
Lazy Loading Pattern — used for both maps
// In any page file (e.g. locations/page.tsx, booking/page.tsx)
import dynamic from 'next/dynamic';

// MapLibre = ~750 KB. With ssr:false, it is NEVER included in the
// server-rendered HTML or the initial JS bundle. The browser
// downloads it only when the component first renders on the client.

const ClinicMiniMap = dynamic(

  setCoverageZones(zonesData);  // instant — already in the JS bundle
}, []);
